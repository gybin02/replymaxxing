# BossMaxxing - Boss直聘专版 Chrome 扩展程序

专为 **Boss直聘 (`*.zhipin.com`)** 深度定制的 AI 求职破冰、高情商回复与 JD 简历重构助手。

---

## 一、 核心功能亮点

1. **黄金前 30 字破冰打招呼（Opener）**
   * 自动读取 Boss直聘岗位详情页/列表页的岗位名称、薪资、公司与 JD 职责痛点，结合您的个人量化成果生成手机一屏（80~110字）高回复率开场白，告别已读不回。
2. **高情商聊天回复与阶段诊断（Reply）**
   * 自动识别 Boss直聘聊天窗口（`/web/geek/chat`）的历史对话，诊断当前所处阶段（`破冰打招呼` -> `发简历与亮优势` -> `高频盘问与排雷` -> `锁定面试与谈薪` -> `已读不回二次激活`）。
   * 内置**离职原因、空窗期解释、温和谈薪不降价、顺势发简历约面、已读不回二次跟进**一键微调按钮。
3. **100% 防封号安全机制（“始终由你点击发送”）**
   * 点击「填入 Boss 聊天框」仅通过原生 `InputEvent` 模拟真实打字填入输入框，绝不自动点击发送按钮，彻底规避 Boss直聘滑块与封号风控。
4. **按岗位 JD 一键定制简历（STAR + XYZ 法则）**
   * 针对当前浏览的 Boss直聘岗位 JD 一键改写简历，展示匹配度提升（如 `58% -> 89%`），高亮 `[提升X%]` 待填数据占位符，支持在线所见即所得编辑并一键导出 **A4 PDF** 或 **Word (`.docx`)**。
5. **求职者（牛人） & 招聘方（Boss/HR/猎头）双模式切换**
   * 既支持牛人找工作破冰，也支持招聘方根据牛人亮点生成走心邀约话术。

---

## 二、 安装与使用步骤

1. **启动服务端 Worker**：
   ```bash
   cd /Users/airbrush/Chrome/server
   npm install
   npm run dev
   ```
2. **在 Chrome 中加载 Boss直聘专版插件**：
   * 打开 `chrome://extensions/`
   * 开启右上角 **「开发者模式」**
   * 点击左上角 **「加载已解压的扩展程序」**，选择 `/Users/airbrush/Chrome/boss_zhipin_src` 目录
3. **开始使用**：
   * 打开 [Boss直聘 (`www.zhipin.com`)](https://www.zhipin.com)，在任意岗位页点击页面上的 **`✦ AI 定制打招呼`** / **`✦ 按此JD改简历`**，或在聊天页点击 **`✦ AI 帮我回`**，即可自动呼出右侧工作台。
